  3. 2026-09-22 10:40

    Punca sebenar URL awam gagal: rangkaian sekat port 7844

    • Error 1033 dari Cloudflare bermakna cloudflared tidak dapat mendaftar dengan edge Cloudflare. Ia bukan masalah halaman atau pelayan tempatan, kerana tempatan kekal 200.
    • Ujian terus pada rangkaian semasa: port 7844 ke edge Cloudflare (198.41.200.13, 198.41.192.7, 198.41.200.193, 198.41.192.167) gagal cap masa setiap kali, tetapi port 443 dan 80 pada IP yang sama terbuka dalam 0.02 saat.
    • DNS keluar juga ditapis: UDP 53, TCP 53 dan DoT 853 ke 8.8.8.8, 1.1.1.1 dan 9.9.9.9 semuanya gagal. DoH ke cloudflare-dns.com dipintas dan dipulangkan halaman sekatan FortiGuard SDNS. Hanya DoH ke 1.1.1.1 berjaya.
    • Kesimpulan: tunnel Cloudflare mustahil hidup pada rangkaian ini, sebab cloudflared hanya boleh keluar melalui port 7844 dan tiada pilihan port lain dalam versi ini.
    • Pengawas dashboard_watchdog.py dipasang sebagai cron setiap 15 minit: menghidupkan semula pelayan tempatan bila mati, memulakan semula tunnel bila 7844 terbuka, dan senyap bila rangkaian masih menyekat.
    • Ujian kebenaran untuk pilihan hosting lain: token tunnel Cloudflare boleh mengubah DNS reidworks.my tetapi tidak boleh buat Worker atau Pages. Token GitHub boleh push pada repo terpilih tetapi tidak boleh buat repo baharu atau hidupkan Pages.
    • Jalan keluar yang disyorkan: hos statik atas port 443 (Worker Cloudflare dengan laluan hostname), sebab 443 terbuka pada rangkaian ini dan pada rangkaian biasa.
